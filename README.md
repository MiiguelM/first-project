# First Project

Projeto simples em C para praticar lógica de programação.

## 📌 Funcionalidades
- Soma de números
- Verificação de número par ou ímpar

## 🗂 Estrutura
- `soma/` → programa de soma
- `par-ou-impar/` → verificação de par ou ímpar

## 🚀 Tecnologias
- Linguagem C

## ▶️ Como executar
Compile:
gcc soma.c -o soma

Execute:
./soma
